# Crooked Windmill Engineering homepage

A responsive, dependency-light GitHub Pages landing page.

- `index.html` — page structure and copy
- `styles.css` — visual system and responsive layout
- `script.js` — mobile navigation and current year
- `assets/windmill-mark.svg` — simplified gold windmill mark

To deploy, upload the contents of this folder to the root of `crookedwindmilleng.github.io` on `main`, with GitHub Pages publishing from `main` / `(root)`.

Before public launch, review the capability descriptions and project status wording, and decide whether to publish a contact method. The page currently uses Google Fonts with system fallbacks.
